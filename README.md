# Particle Heart Animation

An animated particle-heart scene built with Python and Tkinter. Click **开始** (Start) to watch particles gather into a heart while the Chinese phrase “心之所向 / 爱之所往” appears vertically in two columns on the left. The scene uses a black background and settles after the animation finishes.

## Requirements

- Python 3.10 or later
- Tkinter, included with most standard Python installations
- PyCharm

No third-party Python packages are required.

## Run

Open `particle_heart.py` in PyCharm, select a Python interpreter with Tkinter available, and run the file. The supported launch path for this project is PyCharm. Other IDEs and terminals have not been verified, so running it elsewhere is not guaranteed to work without errors.

## Controls

- Click **开始** or press `Enter` to begin
- Press `Space` to pause or resume
- Press `F11` to toggle fullscreen
- Press `Esc` to exit

## Project File

- `particle_heart.py` — the particle animation

# 粒子爱心动画

这是一个使用 Python 和 Tkinter 制作的粒子爱心动画。点击「开始」后，粒子会汇聚成爱心，画面左侧会逐字显示两列竖排文字「心之所向 / 爱之所往」。背景为纯黑色，动画结束后画面会定格。

## 运行要求

- Python 3.10 或更高版本
- Tkinter（大多数标准 Python 安装已包含）
- PyCharm

无需安装第三方 Python 包。

## 运行方式

在 PyCharm 中打开 `particle_heart.py`，选择包含 Tkinter 的 Python 解释器，然后运行文件。本项目指定使用 PyCharm 运行；其他 IDE 和终端环境未经验证，无法保证不会报错。

## 操作

- 点击「开始」或按 `Enter` 开始
- 按 `Space` 暂停或继续
- 按 `F11` 切换全屏
- 按 `Esc` 退出

- `particle_heart.py` — 粒子爱心动画程序
